## Hướng dẫn chạy dự án

### Yêu cầu
- Node.js >= 18
- npm hoặc yarn

### Cài đặt & chạy

```bash
# Clone repo
git clone https://github.com/buiphuocvu/ten-du-an.git
cd ten-du-an

# Cài dependencies
npm install

# Chạy development server
npm run dev
```

Mở trình duyệt tại `http://localhost:5173`

### Build production

```bash
npm run build
```

Output nằm trong thư mục `dist/`
